# Model comparison sources, ranked

Checked 2026-10-11. Every row below was fetched today unless marked "unverified". "Gameable" covers two risks: the vendor runs or funds the board, or entrants submit their own scores or tune for a public test set.

## The monthly check (what a recurring agent should read)

Run these in this order on the 1st of each month. The first three have machine-readable access, so an agent can diff them without scraping.

1. **Vercel AI Gateway model list and endpoints.** This is the source of truth for slugs, prices, price tiers, context windows and per-provider latency, because it is what GBG Ops actually calls. `GET https://ai-gateway.vercel.sh/v1/models` needs no auth ([docs](https://vercel.com/docs/ai-gateway/models-and-providers)). For each model in `model-matrix.json`, also read `GET https://ai-gateway.vercel.sh/v1/models/{creator}/{model}/endpoints`. That returns the price tiers (for example the Haiku 5.5 >100K-token tier) and the latency and throughput figures that the bare list leaves out.
2. **Artificial Analysis free API.** Independent runs of the Intelligence Index, plus price, output speed and TTFT. `GET /data/llms/models`, `x-api-key` header, 1,000 requests a day, attribution required ([docs](https://artificialanalysis.ai/documentation)).
3. **Epoch AI Benchmarking Hub.** An independent cross-check (Epoch Capabilities Index plus 89 benchmarks). CSV download and a Python client, CC BY 4.0, updated 2026-10-11 ([hub](https://epoch.ai/benchmarks)).
4. **Scale Labs (SEAL) leaderboards.** The best signal here for agentic coding (SWE-Bench Pro V2, SWE Atlas), tool use (MCP Atlas) and finance reasoning. It has no export, so the agent reads the page ([leaderboard](https://labs.scale.com/leaderboard)).
5. **Our own eval.** The about-50 labelled GBG Ops messages from Phase 0 ticket F, plus one golden task per workflow. Public boards narrow the shortlist and our own eval makes the final call. Any model change in `model-matrix.json` needs a pass here first.

Optional fifth public source: the **AI Gateway leaderboard export** (`GET https://vercel.com/api/ai/leaderboard-export?dataset=models&modality=text`, JSON or CSV, CC BY 4.0) ([docs](https://vercel.com/docs/ai-gateway/leaderboards)). It measures adoption, not quality. Use it to spot new models worth a trial.

## Things the monthly agent should watch for

- **Slug format.** The gateway uses dots in versions (`anthropic/claude-sonnet-5.5`), while Anthropic's native API IDs use hyphens (`claude-sonnet-5-5`) ([gateway list](https://ai-gateway.vercel.sh/v1/models), [Anthropic models](https://platform.claude.com/docs/en/about-claude/models/overview)). Configs must use the gateway form.
- **Price tiers hidden from the list.** Haiku 5.5 costs 5x above 100K prompt tokens. GPT-6 Luna and GPT-6.1 Sol cost more above 272K. These show only in `/endpoints`.
- **Promotions.** Gemini 3.8 Flash is $0.75/$3.75 through 2026-12-31 and $1.50/$7.50 from 2027-01-01 ([Google](https://ai.google.dev/gemini-api/docs/pricing)). The gateway directory shows several "x% off" badges (DeepSeek V4.1 Flash, GLM-5.3 Flash) without a list price.
- **Peak pricing.** DeepSeek's and Alibaba's endpoints for DeepSeek V4.1 Flash list "Peak 2x" time windows ([endpoints](https://ai-gateway.vercel.sh/v1/models/deepseek/deepseek-v4.1-flash/endpoints)).
- **Not on the gateway.** Gemini 4 Argon ranks #8 on AA (53), but access is limited to Google's Fairwind program ([korben.info, 2026-10-01](https://korben.info/es/gemini-4-argon-supera-gpt-6-claude-codigo-inaccesible.html)), and no gateway page resolved. Skip it until it appears in `/v1/models`.
